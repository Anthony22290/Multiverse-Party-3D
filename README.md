# MULTIVERSE PARTY 3D

Proyecto Unity para un juego social multijugador 3D de minijuegos, con estética cartoon low-poly y un personaje modular compartido.

## Estado

Etapa inicial de producción. El proyecto contiene una base de Unity y recursos de arte; las funciones descritas en el GDD son propuestas y no se consideran implementadas hasta que puedan jugarse y verificarse.

## Requisitos

- Unity `6000.5.6f1` (Unity 6)
- Windows PC como plataforma inicial
- Dependencias declaradas en `Packages/manifest.json`

Photon Fusion 2 todavía debe comprobarse en el proyecto antes de implementar o documentar código que dependa de esa API.

## Abrir el proyecto

1. Abre Unity Hub y elige **Add project from disk**.
2. Selecciona la carpeta del repositorio.
3. Usa la versión de Unity indicada arriba.
4. Abre `Assets/001_Scenes/SampleScene.unity`.

## Skills del proyecto

Las instrucciones específicas para Codex están en `.agents/skills/`. Cubren Photon Fusion 2, arquitectura Unity, prototipado de minijuegos, pruebas multijugador y estilo visual.
