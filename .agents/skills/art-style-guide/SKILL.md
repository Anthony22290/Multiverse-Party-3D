# Visual direction

Use for visual asset selection, scene dressing, character customization, or UI styling in this project.

- Keep the shared direction cartoon low-poly: rounded readable forms, saturated palette, simple materials, and consistent scale and lighting.
- Vary each mode's atmosphere while preserving a recognizable common character and visual language.
- Reuse the same modular humanoid and rig across modes. Keep collider and gameplay statistics consistent across cosmetic choices.
- Prefer source assets already in the project. Preserve Unity `.meta` files and check the source and license before adding or redistributing third-party resources.
- Avoid adding visual complexity that makes gameplay objects, teams, interactables, or hazards hard to read.
